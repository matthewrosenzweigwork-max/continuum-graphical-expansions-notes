# Production plan and acceptance gates

## Current status
Setup only. No literature dossier, frozen theorem set, lecture draft, or mathematical review has been completed by this setup step.

## Sequence
1. **Repository scaffold.** Keep canonical sources and history here. The repository is public, overriding the private visibility proposed in the supplied plan.
2. **One focused literature dossier.** Establish sources, precise statements, applicability, and gaps. Do not begin writing all lectures at this stage.
3. **Audit and theorem freeze.** Audit the dossier; freeze principal statements, hypotheses, notation, and dependency order before drafting.
4. **Blueprint and first lecture.** Prepare a Pro-assisted blueprint, then draft Lecture 1 only.
5. **Independent review and source integration.** Obtain independent mathematical review; resolve findings; compile sources and check citations. Commit accepted sources and a review-resolution record.
6. **Iterate and consolidate.** Repeat for accepted lectures/workshops; perform an end-to-end mathematical, notation, dependency, and compilation audit.

The supplied plan envisages a separate ChatGPT Project called **Continuum Graphical Expansions** and specialist research/writing/review roles. Creating this repository does not mean that those services, consultations, or drafting sessions have been launched.

## Per-lecture acceptance checklist
- [ ] Scope and prerequisite dependencies agreed
- [ ] Principal statements and hypotheses explicit
- [ ] Full proofs and interchanges checked
- [ ] Examples and factorial/normalization checks included
- [ ] Citations verified against sources
- [ ] Exercises and solutions included
- [ ] Independent mathematical review complete
- [ ] Review findings resolved or explicitly retained as open
- [ ] LaTeX compiles and visual output checked
- [ ] Accepted source and review record committed

## Final deliverables
Complete LaTeX source and PDF; verified bibliography; editable diagram sources; exercises with solutions; notation glossary; dependency/theorem register; independent review and resolution documentation.
